# Juncts for Claude

Read, draft and organize messages in your connected Juncts inboxes from Claude.

- `plugin/` is the Claude plugin (inbox skill and MCP server config).
- Requires a Juncts account (https://juncts.com), Juncts open in a signed-in browser, and Agent access enabled in Settings → Agents.
